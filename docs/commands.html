Commands

Telegram and Discord commands

  • Telegram and Discord share one list of commands. Each row below gives both names.
  • Most commands act on the current instance (/setmain, /instance main); fleet commands act on the current planet or moon (/celestial).
  • /help on Telegram and /tgoat help on Discord list every command with its syntax.
  • On Discord, seven costly commands ask you to confirm. Telegram runs them at once, and answers only the configured chat.

Telegram and Discord share one list, so a command does the same on both. On Telegram, type the command in the configured chat. On Discord, type /, pick the command and fill in its options; Discord suggests values as you type. /help (Telegram) and /tgoat help (Discord) list every command with its syntax.

Most commands act on the current instance. Change it with /setmain or /instance main. On Discord, these commands also take an optional instance option, to act on another instance once.

Fleet commands act on the current celestial, the planet or moon you pick with /celestial (Telegram) or /celestial select (Discord).

On Discord, seven commands ask you to confirm before they run. The tables mark them "Confirm on Discord". Telegram runs them at once. See Buttons and confirmation.

Telegram

Set up the bot in the web interface, with tgoat setup, or in config/tgoat.json: TelegramMessenger.Active, TelegramMessenger.ChatId and the token TelegramMessenger.API (kept in secrets.json). Only the configured chat can send commands. For Discord, see Discord bot.

Notifications start with the instance, then, when a feature sends them, its name in bold, such as Directives or AutoMine. When the game session is lost too often, one notification says when TGoat will log in again (see Notifications).

When TelegramMessenger.TelegramAutoPing.Active is on, the sign of life repeats every TelegramMessenger.TelegramAutoPing.EveryHours hours (1 by default).

Commands for the current instance

On Telegram, /start<x> and /stop<x> take expe, defender, automine, autoresearch, lifeformautomine, lifeformautoresearch, autofarm, autodiscovery or brain (the whole Brain), as in /startautofarm. On Discord, you pick the feature in a list.

Start and stop turn a feature on or off whatever its setting, without changing the settings. Add a duration to make it temporary, as in /stopautofarm 4h or the duration option on Discord. When the choice ends, and what still holds a feature you turned on, is in Turning a feature on or off.

In the terminal: tgoat login

tgoat login opens a browser window on the Gameforge login. You sign in and pass any check yourself, and TGoat keeps the session token.

  • tgoat login [--instance <name>] [--browser <path>] signs in on the computer that runs TGoat. A running TGoat picks the token up and connects. --instance is needed when there are several accounts. With no account yet, it tells you to run tgoat setup. See Sign in with your browser.
  • tgoat login --to "<address>" --code <code> [--instance <name>] signs in on this computer for a TGoat that runs elsewhere. Copy the whole command from the web interface. Ctrl+C cancels. See TGoat on another computer.
